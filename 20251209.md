# obtener información del hardware

## Obtener información del micro

```powershell
Get-WmiObject CIM_Processor
```

## Obtener informaición de la RAM
```powershell
$memoria = Get-WmiObject CIM_PhysicalMemory | Select-Object -ExpandProperty Capacity | Measure-Object -Sum
```


## Obtención información de la BIOS
```powershell
Get-WmiObject Win32_Bios 
```

## Parches de seguridad instalados
```powershell
Get-CimInstance -ClassName Win32_QuickFixEngineering
```

## Obtención del espacio en disco
```powershell
Get-CimInstance -ClassName Win32_LogicalDisk -Filter "DriveType=3"
```

## Cómo crear una transcripción de lo que aparece3 en pantalla a un fichero antes de utilizar Write-host

```powershell
# 1. Definimos el nombre del archivo con la fecha de hoy para que no se sobrescriba
$fecha = Get-Date -Format "yyyy-MM-dd_HH-mm"
$nombreArchivo = ".\Auditoria_Seguridad_$fecha.txt"

# 2. Iniciamos la grabación (Todo lo que pase en pantalla se guardará en el txt)
Start-Transcript -Path $nombreArchivo -NoClobber

# aquí escribes tu auditoriía

stop-Transcript

#fin
```

## obtener puertos abiertos en una red

```powershell
# 1. Definimos la red y los puertos que queremos escanear
$net = "10.10.0."
$ports = 22, 80, 443, 3389, 8080 # Puedes agregar los puertos que necesites aquí

# 2. Iteramos por cada host (del 1 al 254 usualmente)
1..254 | ForEach-Object {
    $ip = "$net$_"
    
    # 3. Iteramos por cada puerto definido arriba para la IP actual
    foreach ($port in $ports) {
        $socket = New-Object Net.Sockets.TcpClient
        
        # Usamos Try/Catch para manejar la conexión limpiamente sin errores en pantalla
        try {
            # Intentamos conectar. Si falla, va al bloque 'catch'
            $result = $socket.ConnectAsync($ip, $port).Wait(100) # Timeout rápido de 100ms
            
            if ($socket.Connected) {
                Write-Host "ABIERTO: $ip en el puerto $port" -ForegroundColor Green
                $socket.Close()
            }
        }
        catch {
            # Si falla la conexión, simplemente continuamos (puerto cerrado o filtrado)
            $socket.Close()
        }
    }
}
```
