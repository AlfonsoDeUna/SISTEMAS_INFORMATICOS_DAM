# Como acceder a los procesos de windows

Un proceso es una tarea en ejecución

```powershell
Get-process 
```

# Obtener los solo el id y el nombre de proceso
```powershell
Get-Process | Select-Object Id, ProcessName
```
#Obtener el %cpu
```powershell
Get-Process | Select-Object Id, cpu
```
# Tipos de salida de los comandos
# Obtener información en formato lista
```powershell
Get-Process | Format-List
```
# Obtener TODA la información de los procesos
```powershell
Get-Process | Select-Object * 
```
# Obtener TODA la información de los procesos pero desde una pantalla
```powershell
Get-Process | Select-Object * | Out-GridView
```
# VER COMO PODEMOS FILTRAR INFORMACIÓN DE LOS COMANDOS

# Obtener todos los procesoso que pertenezcan a chrome
```powershell
Get-Process | Where-Object ProcessName -EQ "chrome"
```
# Obtener todos los procesos que sean del notepad
```powershell
Get-Process | Where-Object { $_.ProcessName -eq "notepad" } 
```

# Abre un programa del ordenador.
```powershell

```
## Otros ejemplos vistos en clase

```powershell
Get-Process | Sort-Object Handles 

Get-Process | Sort-Object Handles -Descending
```
# Obtener las primeras cinco líneas de los procesos que se están ejecutando.
```powershell
Get-Process | select-object -first 5
```
#Obtener el primer proceso de la salida.
```powershell
Get-Process | select-object -first 1

Get-Process | Sort-Object Handles -descending | Select-Object -first 1
```
#agrupar los procesos por nombre de proceso

```powershell
get-Process | Group-Object ProcessName
```

# los procesos ordenados por ID

# Obtener los procesos por prioridad

```powershell
$processes = Get-Process
$processes | Sort-Object { $_.PriorityClass } | Format-Table -View Priority
```

# EJERCICIOS PARA RESOLVER EN CLASE

### Ejercicio 1: Listar todos los procesos cuyo nombre sea exactamente "svchost". Solo queremos ver el ID y el Nombre.

### Ejercicio 2: Mostrar todos los procesos que tengan más de 200 Handles (manejadores).

Pista: Tienes que mirar la propiedad Handles y usar el operador "mayor que" (-gt).

### Ejercicio 3: Encontrar procesos que tengan menos de 50 Handles.

Pista: El operador para "menor que" es -lt (Less Than).

### Ejercicio 4: ¿Cuáles son los 3 procesos que más CPU están consumiendo en este momento?

Instrucción: Ordena por CPU de forma descendente y quédate solo con los 3 primeros.

### Ejercicio 5: Queremos ver el proceso con el ID más alto del sistema. Muestra solo su nombre y su ID.

Instrucción: Ordena por ID.

### Ejercicio 6: Agrupa todos los procesos por su nombre (Name) para ver cuántos hay de cada uno.
